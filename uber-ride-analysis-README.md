# Uber Ride Analysis

Exploratory data analysis on Uber ride data — cleaning raw trip records and uncovering demand patterns across time of day, day of week, and trip type.

## What this project does
- Loads and cleans a raw Uber ride dataset (handles missing values, fixes data types, parses timestamps)
- Explores ride volume trends by hour, day, and trip category
- Visualises findings with charts to make patterns easy to read at a glance

## Tech stack
- Python
- Pandas
- Matplotlib / Seaborn *(adjust to whichever you actually used)*
- Jupyter Notebook

## How to run
```bash
pip install pandas matplotlib seaborn jupyter
jupyter notebook uber_ride_analysis.ipynb
```
